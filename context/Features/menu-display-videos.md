
# Prevent idle screen via video or other.

## Overview.
Situation: so this site entirely is meant for the site's admin, it is not a portal for customers to place orders. The primary reason it was created was to show the menu items on the two screens that were not being utilized in the physical store. I was tasked with getting the menu items to show on those screens. I decided to create an app that would be able to update the items which is what we have.

In order to get the menu items displaying, I simply zoomed out and took screenshots (see @screenshots/sandwich-display.png and @screenshots/other-food-display.png). This normally would be enough, however, the TV would timeout and show the screen saver after a while. So, my solution was to use snip tool's video capture on the screens displaying the menus to get a pair of 5 second videos to play on loop to prevent the TV going idle.

Now that we have background context, for this particular task, I would like a feature that would play either menu screen on video loop, or any other way you may know of that will prevent the display monitor from going idle. This needs to be done from the admin backend screen.
